# Smart UV — نموذج تجريبي للمراجعة قبل التصدير

أداة `tools/smart_uv.py` ترشّح مناطق تغيّر في الخامة المحسّنة **المستخدمة في UV فعلاً**، وتقترح استعادة أجزاء من الأصل المكبّر. هي أداة فرز، **وليست نموذج تعرف على اليد أو الحذاء أو الوجه**: لا تعرف معنى الصورة ولا تميّز آلياً خطأ UV من تغيير فني مقصود. قد تفوّت العيب، وتضع إنذاراً خاطئاً، أو تنتج إصلاحاً أسوأ. يلزم فحص بشري للموديل واختبار داخل اللعبة؛ لا تعتمدها إصلاحاً تلقائياً لكل السكنات.

## مثال فعلي وحدوده

[الأطلس ودرجات التغيّر](smart-uv-example/id41-atlas.jpg) و[الموديل من اتجاهين](smart-uv-example/id41-model.jpg) لـID 41 (`hfyst`). التحديد الأبيض في خريطة الحرارة هو الاستعادة المقترحة. عند الإعدادات الافتراضية رُشّحت بلاطة واحدة فقط (0.39% من الأطلس) وقطعت حدودها تقريبياً أربعة مثلثات. **النتيجة لا تستعيد كامل منطقة اليد المتأثرة**؛ هذا مثال على كشف جزئي، وليس إصلاحاً معتمداً أو بديلاً عن `Reviewed-overrides`. لم تُختبر داخل اللعبة.

## المتطلبات

Python 3 وPillow وnumpy وnumba ونسخ المصادر التالية، مع الحفاظ على هيكل المجلدات الأصلي:

- [PF_Skins عند 977b524](https://github.com/ayoubgalai22-web/PF_Skins/tree/977b5240074e68013ed0f4e0bb95decb962f6993): صور `SkinID*.png` الأصلية ومجلد `Authentic_Peds_Remaster`.
- [sa-skins عند 988023b](https://github.com/kewka/sa-skins/tree/988023bd6721a73b6d4d7febad440f9ea664dfb0): `data/mta.json` وملفات `public/skins/*.txd` و`*.dff`.
- [DragonFF عند 319847f](https://github.com/Parik27/DragonFF/tree/319847f7803f102c5aa31fa38e8b3284117db40a): يستخدم `gtaLib` من مسار المشروع مباشرة.

مثال تثبيت الاعتماديات داخل بيئة افتراضية:

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install numpy pillow numba
```

## الاستعمال

من جذر المستودع، استبدل المسارات بمكان المصادر على جهازك. المجلد المقترح يجب ألا يكون موجوداً مسبقاً؛ لا يتغير أي ملف إدخال:

```sh
python uv_review/tools/smart_uv.py prepare \
  --dragonff /path/to/DragonFF --skins /path/to/PF_Skins \
  --originals /path/to/sa-skins --id 41 --out /path/to/review-41
```

راجع `preview.jpg` للأطالس ودرجات التغيّر (الأبيض حول البلاطات المقترحة)، و`model-preview.jpg` للموديل، و`report.json` لنسبة الاستعادة وعدد المثلثات القاطعة للحدود تقريبياً و`model_preview_missing_textures` للخامات المفقودة المعروضة بالرمادي. `mask.png` يبين كامل البلاطات المستعادة؛ `proposal.png` هو الخليط. إن لم تُرشّح أي بلاطات فهذا **لا يعني سلامة السكن** ولا يُنتج التصدير شيئاً. إذا فشل التحضير بعد إنشاء المجلد فقد تبقى ملفات جزئية؛ ابدأ بمجلد جديد.

فقط إذا أعجبتك النتيجة وبعد المراجعة، صدّر اقتراح TXD باسم اللعبة إلى مجلد منفصل:

```sh
python uv_review/tools/smart_uv.py approve \
  --dragonff /path/to/DragonFF --proposal /path/to/review-41 \
  --output /path/to/approved-txd
```

الاعتماد صريح، لا يتم تثبيت أي شيء في اللعبة، ولا يُستبدل ملف موجود في مجلد الإخراج. يتحقق التصدير من بصمات المدخلات وملفات الاقتراح وينتج TXD من النسخة الأصلية ثم يفحص الخامة وباقي الخامات؛ لا تنقل أو تعدّل الملفات قبل التصدير. لا يُقبل تعديل `mask.png` أو `proposal.png` يدوياً في هذه النسخة؛ أعد التحضير بإعدادات مختلفة. يمكنك بعدها عمل نسخة احتياطية من `gta3.img` وتجربة TXD يدوياً بمحرر IMG. ملفات TXD دون صورة محسنة تُترك دون تغيير، وتُرفض بدلاً من توليد اقتراح لها.

## الطريقة والقيود

- يقارن الاختلاف اللوني والحواف بعد تنعيم الصورتين ضمن شبكة 16×16 وعلى مساحة UV المغطاة. الدرجة ليست احتمال خطأ. البلاطات قليلة تغطية UV مستبعدة. يُرتّب المرشحين ثم يختار حتى 15% من مساحة الأطلس افتراضياً؛ عدّل `--threshold` (الافتراضي 0.18) و`--max-fraction` (الافتراضي 0.15) بين 0 و1، ويجب إعادة المراجعة. تختلف النتيجة كثيراً حسب العتبة.
- يستعيد كل بلاطة مختارة من الأصل المكبّر بـLanczos، حتى خارج منطقة UV داخل البلاطة. هذا يزيل تفاصيل HD فيها وقد يُحدث فواصل وتغيّر ألوان؛ عدد المثلثات القاطعة تقريبي عند 256 بكسل، وليس قياساً لظهور الفواصل.
- المعاينة عبارة عن إسقاط ثابت من اتجاهين، وليست محرك اللعبة؛ لا تشمل التحريك والإضاءة وmipmaps وجميع تحويلات اللعبة. خامة مفقودة تُعرض بالرمادي وتُسجّل في التقرير. يمكن أن تكون الزوايا مضللة.
- يدعم صوراً محسنة معتمة بدقة 1024×1024، وأصلاً معتماً، وTXD من نوع D3D9، وخامات UV ملفوفة؛ يفشل في الحالات غير المدعومة أو إذا تعذرت مطابقة خامة أصلية واحدة. التصدير يخزن الخامة المستبدلة كـXRGB32 بدون mipmaps ويحفظ بقية الخامات. CJ مستبعد.
- الاختبارات: `python -m unittest discover -s uv_review/tests -v`. الاختبارات الاصطناعية لا تثبت دقة كشف أخطاء UV الفعلية.
